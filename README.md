# Автомонтаж ИИ-роликов

Локальный инструмент: из озвученных клипов собирает готовый вертикальный ролик —
склейка по порядку → вырез лишних пауз → пословные субтитры (караоке, жёлтое активное слово).
Всё локально и бесплатно: **ffmpeg + faster-whisper + Pillow**. Без CapCut.

## Установка

```bash
python3.12 -m venv venv
./venv/bin/pip install faster-whisper Pillow num2words flask
```
Нужен установленный `ffmpeg` (например `brew install ffmpeg`).

## Веб-интерфейс (проще всего)

```bash
./venv/bin/python webapp.py
# открой http://127.0.0.1:5001
```
- выбираешь папку-источник клипов и папку-назначение (кнопка «Обзор…»);
- правишь порядок, текст реплик и `trim` по каждому клипу;
- жмёшь «Смонтировать» — результат называется автоматически `video1.mp4`, `video2.mp4`, …

## Командная строка

```bash
./venv/bin/python montage.py --in <папка_клипов> --out out/video1.mp4
```
Порядок и текст берутся из `clips.json`. Полезные флаги: `--model`, `--words`, `--keep-silence`.

## Монтажные паспорта сцен

Текст и подсказки монтажа можно готовить в чате со сценарием — см. `ПРАВИЛА.md`
и `ПРОМТ_для_чата-сценария.md`. Парсер `make_clips.py` собирает из них `clips.json`:
```bash
./venv/bin/python make_clips.py   # in/scenes.txt → clips.json
```

## Структура

| Файл | Назначение |
|---|---|
| `montage.py` | ядро: склейка, вырез пауз, субтитры, прожиг |
| `webapp.py` | веб-интерфейс (Flask) |
| `make_clips.py` | `scenes.txt` → `clips.json` |
| `clips.json` | порядок клипов + текст + `trim`/`hook` |
| `ПРАВИЛА.md`, `ПРОМТ_для_чата-сценария.md` | формат монтажных паспортов |

## Требования к ffmpeg

Субтитры прожигаются PNG-оверлеями (не через libass), поэтому подходит любой ffmpeg,
даже собранный без libass.
