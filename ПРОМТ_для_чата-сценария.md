# Промт для чата со сценарием/анимациями (монтажные тайм-флаги)

Скопируй блок между линиями `═══` и вставь **один раз** в тот чат, где пишешь сценарий
и делаешь анимации. После этого он к каждой сцене, помимо промтов, будет выдавать
монтажный «паспорт сцены». Эти паспорта я превращаю в готовый монтаж.

═══════════════════ КОПИРОВАТЬ ОТСЮДА ═══════════════════

С этого момента для КАЖДОЙ сцены, помимо обычных промтов изображения и оживления,
выводи в самом конце сцены монтажный блок строго в таком формате:

[MONTAGE]
file: <короткое отличительное слово из будущего имени клипа: cliff, talks, brushing, finale…>
text: <точная реплика сцены — только произносимые слова>
trim: <tight | normal | loose | none>
hook: <текст плашки на весь кадр — ТОЛЬКО если в сцене нет реплики; иначе строку убери>
keep: <куски, где паузу НЕ резать: слово-метка «эмоция/пауза» или «нет»>
[/MONTAGE]

ПРАВИЛА ЗАПОЛНЕНИЯ
• text — только слова, которые звучат. Числа пиши СЛОВАМИ в правильной форме
  («двадцать процентов», «две минуты», «шестьдесят дней»). Исключение — коды моделей
  («RL 066»): их оставляй латиницей и цифрами. Знаки препинания можно не ставить.
• trim — насколько плотно резать паузы в этой сцене:
    tight  — речь быстрая/энергичная, режь плотно;
    normal — обычная сцена (по умолчанию);
    loose  — оставь воздух, дыхание, комедийную паузу;
    none   — не резать вообще (музыкальный проигрыш, песня, долгий кадр-эмоция).
• hook — заполняй ТОЛЬКО для сцены без реплики (общий план-завязка, титр). Иначе убери строку.
• keep — если в сцене есть пауза «по задумке» (драматический бит, реакция) — напиши «эмоция».
  Если резать всё можно свободно — напиши «нет».

УСЛОВНЫЕ ОБОЗНАЧЕНИЯ ВНУТРИ text (необязательные, ставь по смыслу)
• *слово*      — акцент: это слово выделить (крупнее/цветом).
• ~            — здесь держать паузу, не сжимать тишину (ставь между словами).
• //           — принудительный разрыв: следующее слово начинает новую плашку/строку.
Пример: ставь лайк если ты *за звезду* ~ // а если за обеих пиши сикс севен

ФОРМАТ ВЫВОДА
• По одному блоку [MONTAGE] на сцену, в порядке воспроизведения.
• Блок — в самом конце сцены, после промтов. Ничего лишнего внутри блока не пиши.

═══════════════════ КОПИРОВАТЬ ДО СЮДА ═══════════════════

## Что дальше делаю я (тебе)

1. Ты копируешь все блоки `[MONTAGE]` в файл `in/scenes.txt`.
2. Кладёшь клипы в `in/` (имена любые — лишь бы в `file:` было отличительное слово).
3. Я запускаю:
   ```bash
   ./venv/bin/python make_clips.py    # scenes.txt → clips.json (+ печатает пары клип↔сцена)
   ./venv/bin/python montage.py       # готовый ролик в out/final.mp4
   ```

| `hook` (плашка для сцены без реплики) | ✅ работает |
| `keep` (не резать паузу-эмоцию) | ⏳ следующий шаг |

Задел ничему не мешает: неизвестные флаги парсер просто пропускает, символы из text
снимаются вместе с пунктуацией — так что можно писать паспорта «на вырост» уже сейчас,
а я подключу оставшиеся флаги по ходу.
