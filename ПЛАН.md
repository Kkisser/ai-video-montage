# Автомонтаж озвученных клипов → готовый MP4

Недостающий кусок пайплайна (этап 4 «Монтаж» из `landing_partners.html`).
Достраивает то, что раньше делалось руками в CapCut: **убрать паузы + вшить караоке-субтитры**.
Склейка/хук/плашка-промокод уже есть в `../avtomat/flowbatch/assemble.py` — не дублируем, стыкуемся.

## Вход / Выход
- **Вход:** озвученные видео-клипы (голос уже внутри клипа, вариант RPA/Omni Flash) + известный
  текст реплики на каждый клип (из этапа озвучки промтов по кадрам).
- **Выход:** один готовый вертикальный MP4 9:16 с плотной речью и вшитыми субтитрами.
- Всё бесплатно и локально (faster-whisper + ffmpeg + Pillow), без облачных ключей.

## Конвейер инструмента (`montage.py`)

### 1. Сбор входа
Папка с клипами в нужном порядке + текст на клип. Формат манифеста — `clips.json`:
`[{ "file": "v3_cliff_anim.mp4", "text": "Кого бы ты выбрал..." }, ...]`.
Текст нужен для точного выравнивания (forced alignment вместо чистого распознавания → меньше ошибок в RU).

### 2. Удаление лишних пауз (jump-cut по тишине)
- Извлечь аудио, детект тишины через ffmpeg `silencedetect`.
- Резать паузы длиннее порога (по умолч. ~0.35 c), оставляя запас ~0.08 c по краям, чтобы не рубило слова.
- Вырезать синхронно видео+аудио (ffmpeg `select`/`atrim` + concat) → «плотная» дорожка.
- Порог и запас — параметры (подберём на первом клипе).

### 3. Тайминг слов (forced alignment)
- **После** удаления пауз прогнать плотный звук через `faster-whisper` (word_timestamps=True),
  текст реплики — как подсказка/якорь → пословные тайм-коды на сжатой таймлинии.
- RU-модель `large-v3` (качество) или `medium` (скорость) — параметр.

### 4. Генерация ASS-караоке (стиль CapCut)
- Слова группируются по **1–2** за раз (как в референсе).
- Крупный жирный шрифт, толстая чёрная обводка, снизу-по центру, **активное слово — жёлтое**
  (караоке-тег `\k`), как на приложенном скриншоте.
- Стиль вынесен в параметры (шрифт, размер, цвет активного слова, позиция, регистр).

### 5. Прожиг + финальная сборка
- ffmpeg прожигает `.ass` на видео без пауз (`-vf ass=subs.ass`).
- Опционально передать в существующий `assemble.py` (хук в начале, плашка с промокодом в конце).
- Итог → `out/<name>_final.mp4`.

## Технологии (всё уже в стеке проекта)
- `faster-whisper` — тайминг (упомянут в landing как выбранный инструмент).
- `ffmpeg` — резка тишины, конкат, прожиг ASS.
- `Pillow` — уже используется в `assemble.py` для плашек.

## Открытые вопросы для настройки (подберём на прототипе)
1. **Стиль субтитров:** шрифт (Arial Bold? свой .ttf?), размер, 1 или 2 слова, регистр (как на скрине — строчными), точный жёлтый.
2. **Порог тишины:** сколько считать «лишней паузой» (0.3 / 0.4 / 0.5 c).
3. **Стыковка с `assemble.py`:** вызывать его из `montage.py` или оставить отдельным финальным шагом.
4. **Где лежат клипы+текст:** папка на клип-эпизод + `clips.json`, или читать из `.flow.txt`.

## Первый шаг после утверждения
Прототип на одном клипе (`../1/0625(2).mov` или короткий из `flowbatch/out/`):
один прогон весь конвейер → смотрим MP4 → доводим стиль субтитров и порог пауз.
